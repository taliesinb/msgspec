# @msgspec/msgpack

A tight [MessagePack](https://msgpack.org/) reader/writer whose byte output is
**identical to Python [msgspec](https://github.com/jcrist/msgspec)**. It is the
runtime that [`msgspec.javascript.codec`](../docs/javascript.rst) inlines into
each generated, dependency-free codec module — published here so it can also be
used directly.

- Zero dependencies, ES module (`type: "module"`).
- Smallest-form integer encoding, matching msgspec.
- 64-bit integers round-trip as native `bigint` (exact, no safe-integer
  narrowing).

## Usage

```js
import { Writer, Reader } from "@msgspec/msgpack";

const w = new Writer();
w.mapHeader(2);
w.str("x"); w.int(1);
w.str("y"); w.int64(2n ** 60n);
const bytes = w.bytes(); // Uint8Array

const r = new Reader(bytes);
const n = r.mapHeader(); // 2
```

Most applications won't use this directly — they use a codec generated by
`msgspec.javascript.codec(SomeType)`, which drives these primitives.

## Primitives

`Writer`: `nil`, `bool`, `int` (number), `int64` (bigint), `float`, `str`,
`bin`, `arrayHeader`, `mapHeader`, `ext`, `value` (generic).

`Reader`: `tryNil`, `bool`, `int`, `int64`, `float`, `str`, `bin`,
`arrayHeader`, `mapHeader`, `ext`, `skip`, `value` (generic).

Plus `decArray`, `decSet`, `decMap` helpers.

## Development

```
node --test
```

The source of truth is `src/msgpack.mjs`. After editing it, regenerate the copy
embedded in the Python package with `python scripts/gen_js_runtime.py` (the
Python test suite asserts the two stay in sync).
